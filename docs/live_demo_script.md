# Live Demo Script

1. Open the project and run `streamlit run app.py`.
2. Enter a factual question and click **Generate Response**.
3. Point to the generated response and extracted facts.
4. Show green supported, red contradicted, and orange neutral claims.
5. Open evidence cards and source links.
6. Open **Developer Details** only when explaining models, retrieval, and timings.
7. Repeat with a mixed or false claim to demonstrate hallucination detection.
8. Explain that the same analysis pipeline is used by the CLI benchmark.
